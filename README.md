# Desk

개인 일정 관리 웹앱. 단일 `index.html` 파일로 동작하며 GitHub Pages로 배포합니다.

## 기능

- 월간 캘린더 (대한민국 공휴일 표시, 여러 날짜에 걸친 일정 막대 표시)
- 카테고리별 탭 (연구실 · 학교 · 기타, 설정에서 이름·색·순서를 자유롭게 변경(드래그 정렬))
- 카테고리 안의 하위 과제 (설정에서 추가). 일정마다 과제를 지정하고, 탭에서 과제별 필터·묶어보기
- 할 일 / 일정 구분, 종일 또는 시간 지정, 반복(매일 · 매주 · 매월), 반복 회차별 완료 체크
- D-day 카드 (특정 일정을 홈에 고정 가능), 30일 예정 목록, 지난 미완료 정리
- 목록 탭: 검색 · 카테고리 · 상태 필터
- 일정 안의 체크리스트 (진행률 n/m 표시)
- 선택한 날 목록에서 손잡이를 끌어 우선순위 변경 (마우스·터치), 캘린더와 다가오는 일정에 같은 순서 적용
- 캘린더에서 일정을 드래그해 다른 날짜로 이동 (되돌리기 지원)
- 카테고리 탭의 타임라인(간트) 보기: 과제별 레인, 2·4·8개월 범위
- ICS 내보내기 · 가져오기 (Google 캘린더, 아이폰 캘린더와 연동)
- GitHub Gist 동기화: gist 권한 토큰 하나로 여러 기기에서 같은 데이터 사용 (최신 수정본 우선)
- 마크다운 메모
- 라이트 / 다크 테마, 키보드 단축키 (`N` 새 일정, `T` 오늘, `[` `]` 달 이동)
- JSON 백업 / 복원

## 데이터

기본적으로 브라우저 `localStorage`에 저장됩니다. 여러 기기에서 쓰려면 상단 구름 버튼에서 GitHub 토큰(gist 권한만)을 넣어 비공개 Gist 동기화를 켜세요. 토큰은 브라우저에만 저장되며 서버는 없습니다. JSON 백업과 ICS 파일 교환도 같은 창에 있습니다.

## 로컬 실행

```
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 을 엽니다. 파일을 직접 더블클릭해서 열어도 동작합니다.

## 커스터마이즈

- 공휴일: `index.html`의 `HOLIDAY_FIXED`, `HOLIDAY_DATE`
- 기본 카테고리와 하위 과제: `DEFAULT_CATS`
- 색상 팔레트: `:root` CSS 변수
